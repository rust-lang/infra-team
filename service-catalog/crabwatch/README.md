# Crabwatch

[Crabwatch] audits GitHub Actions workflows across Rust project repositories
using [zizmor] and a centrally maintained
[policy](https://github.com/rust-lang/crabwatch/blob/main/zizmor-policy.yml)
managed by the Infrastructure team.

The repository also provides a CLI for manually auditing repositories.

[Crabwatch]: https://github.com/rust-lang/crabwatch
[zizmor]: https://docs.zizmor.sh/
